01 · GenAI · Local RAG

Local RAG & Agentic Q&A System

“How far can a small local model get when you ask it questions about your own documents?”

GitHub

What I did

Built a retrieval-augmented Q&A system that runs fully on my own machine, then added a ReAct agent that can use tools such as a calculator.

What I learned

  • Chunk size changes retrieval. Different chunk sizes gave noticeably different similarity scores.
  • Hallucinations are detectable. I tested where the model answered without support from the documents.
  • Vector store choice shifts scores. ChromaDB and an in-memory index gave different score ranges for the same queries.

Honest limit: it runs on a local Llama 3 model, which is less reliable at forcing tool use than hosted models.

02 · Process Mining · Case study

Pizzeria Mamma Mia: Order-to-Cash

“Why is a pizzeria with healthy revenue making such thin margins?”

What I did

Analysed the order-to-cash process of a Munich pizzeria (1,998 orders) in Celonis, using the Process and Variant Explorer plus the costs, profits, customer satisfaction and rework views.

What I found

  • Revenue was fine, margins weren’t. The cost pressure came from ingredients and delivery.
  • Few process variants were optimised. Only 19% of them.
  • Products differed a lot. Salami had a 29.6% margin against 40.67% for Calzone.

What a business can do

Improve delivery assignments and ingredient supply, push orders towards the common process paths, promote higher-margin pizzas, and track margins and cost breakdowns over time.
